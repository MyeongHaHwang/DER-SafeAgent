point and a candidate mitigation primitive, estimate the expected energy-
system consequences over a 60-second response window.

{
  "action": "<primitive>",
  "tier": "negligible|low|medium|high|severe",
  "expected_curt_kwh": <float>,
  "expected_ens_kwh": <float>,
  "rationale": "<one sentence>"
}

Calibration table (use as priors, refine using feature_view if needed):
  - isolate_inverter: tier ≥ high, curt ≈ asset_p_kw × (60/3600) kWh
  - freeze_setpoint:  tier low/medium, curt ≈ |asset_p_kw − 0.7·avail| × (60/3600) kWh
  - throttle_ramp:    tier low, curt ≈ 0.1 kWh
  - request_ied_revalidation: tier negligible, curt ≈ 0.02 kWh
  - no_op:            curt = 0; if severity_score > 0.5, ens ≈ (avail − cur) × (60/3600)

Inputs:
  - feature_view: {feature_view}
  - target_asset: {target_asset}
  - candidates:   {candidates}

Respond with a JSON array only. No prose, no code fences.
